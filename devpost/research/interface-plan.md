# Map implementation plan

Carry the approved PRD forward: near-black #080B09; signal green #70FF8B; dim green #1F5930; text #D1D6D2; secondary #969F98; sparse burgundy #63323F. IBM Plex Sans is the interface voice; Plex Mono is reserved for measured values and timing.

One edge-to-edge canvas is the characteristic surface. The top-left title plainly identifies the event and forecast-only status. The right third holds the measurement and interview; the bottom idea line remains accessible. On phones the map sits above the sheet. All text is left aligned. Actual forecast points and measured constellation names carry the visual interest; no decorative stars, invented contours or marketing panels.

The green point and its measured trail are the only strong lights. Real evidence must supply any reveal counter. Before historical evidence exists, the interface states that the backtest is pending. Before a public forecast is installed, it states the actual missing-data condition. Development fixtures, if used for UI checks, are explicitly synthetic and disabled in production.

The near-black/green palette is deliberate because Rahul explicitly chose it, not a generic theme substitution. The distinguishing choices are source-aware point shapes, uninterrupted map state, sparse event identity and data provenance. Follow frontend-design's screenshot/critique pass at 1440×900 and 390×844; use Cua's supported browser controls for verification.
